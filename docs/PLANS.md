# Guía de Planes de Ejecución (PLANS.md)

Para cualquier tarea no trivial (más de un archivo o cambio estructural):

1. Copia `docs/exec-plans/TEMPLATE.md` a `docs/exec-plans/active/<nombre-tarea>.md`.
2. Detalla el contexto, invariantes, desglose de pasos y evidencia de verificación.
3. Al completar la tarea y verificar con tests y linters, mueve el plan a `docs/exec-plans/completed/<nombre-tarea>.md`.
